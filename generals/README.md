# Zero Hour Web route

Mobile launcher at /generals/.

This folder intentionally contains no EA game assets. The launcher expects compiled Generals-WebAssembly artifacts (GeneralsXZH.js / .wasm and the upstream runtime distribution) to be added here before PLAY is enabled.

Upstream engine source: https://github.com/Lolendor/Generals-WebAssembly

Game data must come from the user's legally owned Zero Hour copy and should not be committed to this public repository.
